# Pusat Tuisyen Bestari Didik - Premium Web & Presentation Deck

Official website and standalone presentation deck proposal for **Pusat Tuisyen Bestari Didik** (MOE Registered Tuition Centre).

---

## 🌟 Project Versions

### 1. Presentation Deck Version (`/vanilla-presentation`)
A high-performance, zero-dependency standalone HTML/CSS/JS presentation deck designed for stakeholder presentations and rapid hosting.
- **Theme**: "The Prestigious Academy" (Oxford Navy `#0A192F` & Academic Gold `#D97706`)
- **Key Sections**:
  - Dual-language Header (English / Bahasa Melayu)
  - 5-Slide Hero Showcase with Prestigious Trust Metrics Strip (`13+ Yrs`, `Max 12`, `1,500+`)
  - Quick Course Finder Widget
  - 10 Pillars Bento Grid
  - Academic Syllabus Matrix & Quarterly Diagnostic Report Card Preview
  - Results & Parent Testimonials
  - Interactive Admissions & Consultation Form + Direct WhatsApp Link
- **Vercel Ready**: Includes `vanilla-presentation/vercel.json` with security headers and clean URL routing.

### 2. React + Vite Production App (`/`)
Interactive React single-page application built with React 19, Tailwind CSS, Lucide Icons, and Framer Motion.

---

## 🚀 Getting Started

### Presentation Deck (Vanilla)
Open `vanilla-presentation/index.html` directly in any browser, or serve locally:
```bash
npx --yes serve -p 8080 vanilla-presentation
```
Preview at: `http://localhost:8080`

### React Web Application
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
Preview at: `http://localhost:5173`

---

## 🌐 Deploying Presentation Deck to Vercel

```bash
npx --yes vercel vanilla-presentation --prod
```
Or import this repository to Vercel and set the **Root Directory** to `vanilla-presentation`.
